## Требования

|          | Версия                                        |
| -------- | --------------------------------------------- |
| Node.js  | >= 22.22 (`node -v`)                          |
| pnpm     | любой актуальный (`pnpm -v`)                  |

С npm должно работать без изменений.

## Быстрый старт

```bash
pnpm install
cp .env.example .env
pnpm dev
```

Приложение откроется на <http://localhost:5173> с HMR — правки в `app/` подхватываются без перезапуска.

`.env` необязателен: без него приложение работает с инстансом по умолчанию `https://3100.api.green-api.com`.

## Переменные окружения

| Переменная     | Назначение                                                      | По умолчанию                        |
| -------------- | --------------------------------------------------------------- | ------------------------------------ |
| `VITE_API_URL` | Базовый URL вашего GREEN API инстанса                            | `https://3100.api.green-api.com`     |

Значение попадает в бандл на этапе сборки, поэтому новый инстанс проверяется перезапуском `pnpm dev` (или пересборкой для `pnpm start`).

Файл `.env` в git не попадает (см. `.gitignore`), вариант для репозитория — `.env.example`.

## Команды

| Команда          | Что делает                                                        |
| ---------------- | ----------------------------------------------------------------- |
| `pnpm dev`       | Dev-сервер с HMR на <http://localhost:5173>                       |
| `pnpm build`     | Прод-сборка в `build/client` (`ssr: false`, SPA-режим)            |
| `pnpm start`     | Отдаёт собранный `build/client` на <http://localhost:4173>        |
| `pnpm typecheck` | Генерирует типы роутов (`react-router typegen`), затем `tsc`       |

Проверить прод-режим локально:

```bash
pnpm build && pnpm start   # http://localhost:4173
```
